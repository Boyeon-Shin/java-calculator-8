# java-calculator-precourse

## 문자열 덧셈 계산기
입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현합니다.

## 기능 목록

### 1. 입력 처리
- [x] 사용자로부터 문자열 입력 받기 (Console.readLine() 사용)
- [x] 빈 문자열 입력 시 0 반환

### 2. 구분자 처리
- [x] 기본 구분자(쉼표, 콜론) 지원
- [x] 커스텀 구분자 추출 기능
    - [x] "//"와 "\n" 사이의 문자를 커스텀 구분자로 인식
    - [x] 커스텀 구분자가 있을 경우 해당 구분자로 문자열 분리

### 3. 문자열 파싱
- [x] 구분자를 기준으로 문자열 분리
- [x] 분리된 문자열을 숫자로 변환

### 4. 계산 기능
- [x] 추출된 숫자들의 합 계산
- [x] 결과 출력

### 5. 예외 처리
- [x] 음수 입력 시 IllegalArgumentException 발생
- [x] 숫자가 아닌 값 입력 시 IllegalArgumentException 발생
- [x] 잘못된 커스텀 구분자 형식 입력시 IllegalArgumentException 발생
